# private_diary

会員ごとに自分専用の日記を投稿・管理できるWebアプリケーションです。

Djangoの認証機能を利用してユーザーごとに日記を管理しているため、他のユーザーが投稿した日記は表示されません。

## 機能

**1. ユーザー登録・ログイン**<br>

ユーザーはメールアドレスを利用してアカウントを作成し、ログインできます。

認証機能には`django-allauth`を使用しています。パスワードなどはuuidを用いることで流出を防いでいます。

**2. 日記を投稿する**<br>

ログインしたユーザーは、タイトルや本文、写真などを入力して新しい日記を投稿できます。

投稿した日記には、投稿したユーザーの情報と作成日時が保存されます。

**3. 日記を一覧表示する**<br>

ログインしているユーザーが投稿した日記を、新しい順に一覧表示します。

他のユーザーが投稿した日記は表示されないため、個人専用の日記として利用できます。

**4. 日記の詳細を表示する**<br>

日記一覧から選択した日記のタイトルや本文など、詳しい内容を確認できます。

**5. 日記を編集する**<br>

投稿済みの日記の内容を編集し、変更した内容を保存できます。

**6. 日記を削除する**<br>

不要になった日記を削除できます。

**7. 日記データを保持する**<br>

ユーザー情報や投稿した日記はPostgreSQLに保存されるため、アプリケーションを終了してもデータが保持されます。

## 技術スタック

* フロントエンド：HTML、CSS、Bootstrap 5
* バックエンド：Django 5.2.8（Python）
* データベース：PostgreSQL
* 認証：django-allauth
* UI：django-bootstrap5

## 各ディレクトリの役割

### `private_diary`

プロジェクト全体の設定を管理するディレクトリです。

データベース、言語、タイムゾーン、認証、インストール済みアプリなどの設定を記述しています。

### `diary`

日記に関する機能を管理するアプリケーションです。

日記の投稿、一覧表示、詳細表示、編集、削除などの処理を担当します。

### `accounts`

ユーザー情報や認証に関する機能を管理するアプリケーションです。

カスタムユーザーモデルとして`CustomUser`を定義しています。

### `templates`

Webページとして表示するHTMLファイルを管理します。

共通レイアウトを定義する`base.html`や、トップページを表示する`index.html`などが含まれます。

### `static`

CSS、JavaScript、画像などの静的ファイルを管理します。
